# 说明

这是一个简单的插件，让你可以无视限制播放任意游戏情感动作，无论是否已解锁。<br/>
用法就和在聊天框里输入普通情感动作指令一样，例如 `/tea` 或 `/beesknees`。<br/>
这**不是**解锁外挂。

情感动作会根据你角色当前的状态来播放：坐在地上、坐在椅子上、骑乘、坐在双人坐骑后座、游泳、潜水、手持雨伞或火把、佩戴时尚配饰。这在最初的几个版本里是个问题，现在已经彻底修复了！<br/>

从 2.0.0.0 起，无视限制播放有两种方式。首次启动时会弹出窗口让你选择（如果你之前就在用这个插件），之后随时可以在配置窗口里更改。

## 表情替换

这是新的推荐方式，需要你安装 Penumbra，并且需要和其他玩家配对同步，他们才能看到你无视限制播放的情感动作。<br/>
它不会把动画直接套用到你的角色上，而是由插件寻找一个你已解锁、且表现方式和你要播放的那个相近的情感动作，通过插件自动管理的 Penumbra 模组把两者的动画互换，然后真正播放那个已解锁的情感动作。

## 直接播放

这是最初的方式，不需要 Penumbra。<br/>
动画只在你自己的客户端上套用到你的角色，因此其他人看不到你的情感动作\*。<br/>
\* 除非对方使用了集成了 BypassEmote IPC 的同步插件，否则其他玩家看不到你的情感动作。

默认情况下，直接播放只会从你当前姿态的基准姿势（姿势 0）播放情感动作。<br/>
这是因为当你的角色处于其他姿势时，游戏客户端会重复发送姿势变更封包。这不是插件造成的，而是游戏处理姿势变更的方式导致的。游戏「角色配置 → 操作设置 → 角色」标签页里的「Idle Animation Delay（待机动作延迟）」设置就是原因所在。<br/>
如果你清楚自己在做什么，可以在 BypassEmote 配置窗口里切换到不安全模式。<br/>
请注意，安全模式也不是承诺，它只是让直接播放保持在我比较确定安全的状态下工作。

直接播放用在宠物、NPC 或其他玩家等别的角色上是 100% 安全的，因此对它们播放情感动作时会使用直接播放。

## 指令

- 启用插件后，输入 `/bypassemote` 或 `/be` 可以打开未解锁的情感动作界面。<br/>
- 加上 `c` 或 `config` 参数（`/be c`、`/be config`）可以打开配置窗口。<br/>
- 加上情感动作参数（`/be /tea`、`/be tdance` 等）会直接播放该情感动作。这会强制游戏使用 BypassEmote。<br/>
- 你也可以直接在聊天框里输入情感动作指令（`/tea`、`/tdance` 等）：如果该情感动作已解锁，就交给游戏处理；否则会走 BypassEmote。<br/>
在已解锁该情感动作的情况下使用 `/be <情感动作>` 的一个好用处是：你想用直接播放模式播放带音效的动画。使用 `/be sync` 或 `/be syncall`（前提是你要同步的玩家也在用 BypassEmote 直接播放来播放情感动作），该情感动作关联的音效也会被重置。<br/>
- 使用 `/be sync` 或 `/be syncall` 可以把所有玩家的动画重置到 0，从而实现双人情感动作的「同步」。`/be sync` 只同步正在用直接播放无视限制播放情感动作的玩家，而 `/be syncall` 会同步地图上的所有玩家。<br/>
另外，同步指令会重置情感动作关联的音效，但请注意：只有当该情感动作的所属玩家在用 BypassEmote 直接播放时，这两条指令才会重置音效。如果对方是正常播放情感动作、或走表情替换，则不会重置音效。<br/>
- 选中一个 NPC 后输入 `/bet <情感动作指令>` 或 `/bet stop`，可以把指定动画套用到选中的 NPC 上，或完全停止它。
- 输入 `/bem <情感动作指令>` 或 `/bem stop`，可以把指定动画套用到你已召唤的宠物上，或完全停止它。你不需要选中宠物。<br/>
`/bep` 对应召唤兽，`/bec` 对应陆行鸟，用法相同。

你也可以把任意情感动作制成一个永久的 Penumbra 模组：点击主界面上的「创建模组」按钮，或右键点击一个情感动作并选择「用此情感动作创建模组...」。如果你想让自己某个情感动作固定使用某个动画、而不需要插件做任何额外的事，这个功能很有用。

各项设置我认为已经配置到了最合理的方式，所以你一般不需要改动任何一项。

# 常见问题

**问**：用这个安全吗？<br/>
**答**：用表情替换的话，安全。BypassEmote 会创建一个动画模组，和你在各类模组网站上能找到的模组性质一样。<br/>
用直接播放的话，安全模式会通过强制你处于待机动作 0 来尽量避免风险。我会尽我所能把任何可能的风险降到最低，但在直接播放模式下无法做到 100% 安全。更多信息见 [issue #7](https://github.com/Aspher0/BypassEmote/issues/7)。

**问**：我需要 Penumbra 或其他东西吗？<br/>
**答**：只有表情替换需要。你需要 Penumbra，并且需要和其他人同步／配对。表情替换会创建一个动画模组，需要其他人能看到它才会生效。

**问**：我装了 BypassEmote 和（某个同步插件），但看不到朋友的情感动作，这是 bug 吗？<br/>
**答**：如果你朋友用的是表情替换，你应该能看到。<br/>
如果他用的是直接播放，那就看不到。直接播放模式下 BypassEmote 无法单独起作用，需要同步插件的开发者把本插件的 IPC 方法集成进他们的代码里，才能转发情感动作消息。<br/>
你可以试着请你在用的同步插件的开发者集成 BypassEmote，但如果对方拒绝，也请尊重他们的决定。

**问**：插件提示我当前游戏版本尚未通过审批，这是什么意思？<br/>
**答**：一次游戏更新可能会破坏 BypassEmote 依赖的部分功能。每次更新后，插件的部分功能会自动关闭，直到我完成测试并审批通过。插件每 10 分钟检查一次更新，你也可以在配置窗口里手动检查。在此之前插件仍会继续工作，这**并不**意味着它更不安全，只是你可能需要先停止当前的无视限制播放，才能去播放另一个情感动作。

**问**：我发现了 bug，该怎么报告、在哪里报告？<br/>
**答**：直接在本 GitHub 仓库开一个 issue，说明这个 bug、如何复现，并尽量附上 `/xllog` 窗口里把全局过滤正则设为 `BypassEmote` 后出现的相关报错。
